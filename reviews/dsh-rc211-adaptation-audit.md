# 上游适配与 Webview 系统检查

本记录保存本轮实现和验证边界；长期约束以 [DSH 契约](../docs/dsh-contract.md)、[质量流程](../docs/quality.md)和[能力矩阵](../docs/capability-matrix.md)为准。新增精确版本入口及固定上游来源集中在契约表中，不以 UI 更新提示推断适配完成。

## 实现范围

- 普通会话、审批、提问、子代理和多窗口的用户控制链由 `pnpm test:contracts` 持续验证。停止及撤回操作需要到达 Host；运行状态、可选目录失败和工作区信任变化不能擅自阻挡撤回。
- 会话列表状态与操作分列；任务等功能菜单有可读宽度，空状态完整换行。检查器详情紧邻条目，插件页和共享选择器使用统一主题与布局。
- 导出关闭来源菜单后进入共享模态表面；语言选择器按触发器定位，嵌套 Esc、背景隔离和焦点恢复通过同一弹层栈处理。入场结束后不保留影响 fixed 定位的 transform。
- 同级菜单入口统一最终计算字号、字重及行高；局部菜单和工具详情角色跟随会话字号。
- 更新、连接、错误和欢迎提示合并为默认收起的通知栏。完整通知按需展开并独立滚动，通知栏与聊天主体分配各自的空间。
- 返回最新消息和轨迹详情占用独立行。短窗口下会话外层可以滚动，消息区保留可读高度，输入区仍可到达。
- 消息区高度变化经共享滚动所有者处理；自由阅读和正在进行的用户手势优先。虚拟列表在跟随尾部时保持末条消息可测量，避免一次跳转后因末条高度修正再次偏离尾部。

## 自动验证入口

- [App 连接与用户交互](../apps/webview/src/App.connected.spec.tsx)：真实 Store / 协议链、通知关闭和更新版本记忆。
- [通知栏](../apps/webview/src/features/shell/AppNotices.spec.tsx)：默认收起、完整说明、操作、Esc 及关闭后的焦点。
- [滚动所有者](../apps/webview/src/components/common/useScrollFollow.spec.tsx)：尾部跟随、自由阅读、布局变化和尚未到达 scroll 事件的用户手势。
- [时间线](../apps/webview/src/features/chat/Timeline.spec.tsx)：虚拟化窗口、末条测量与键盘焦点保留。
- [布局规则](../apps/webview/src/styles/layout-contract.spec.ts)与[排版角色](../apps/webview/src/styles/typography-scale.spec.ts)：历史遮挡、定位和字号回归守卫。

完整交付门禁为 `pnpm check`、`pnpm test:contracts`、`pnpm build` 和 `git diff --check`。运行结果须在交付前重新核对；不能把临时脚本或历史通过次数当作当前结果。

2026-10-17 验证结果：`pnpm check` 通过，354 个文件 / 3920 项测试通过，27 个文件 / 29 项测试按环境条件跳过；`pnpm test:contracts` 的 19 个文件 / 309 项测试通过；构建与差异检查通过。跳过的真实运行场景不算通过证据。

## 渲染与现场边界

隔离 Chromium 探针使用真实组件及应用样式，覆盖聚焦 / 经典布局、窄 / 宽 / 短窗口、长文本、亮 / 暗 / forced-colors、键盘和焦点。通知场景检查实际矩形不相交、消息区命中元素、通知内部滚动、输入草稿、阅读位置及短窗口输入区可达性。探针和截图为本地验证产物，不进入扩展包。

本轮 30 组通知 / 消息 / 输入区场景、20 组弹层回归及 51 组会话 / 任务等列表场景通过。另在窄短窗口和普通宽度使用原生滚轮输入，验证通知消失时不会把尚在进行的用户滚动覆盖为旧位置或尾部，两组均通过。

这些结果不等于真实 VS Code Webview 的完整人工验收。AX-01 继续为 `PARTIAL`：仍需在 VS Code 中复核主题、缩放、键盘、读屏、弹层及通知新增 / 展开 / 关闭后的消息和输入区。扩展只能约束自身 Webview 的通知与控件，宿主原生通知由 VS Code 管理。没有执行提交、推送、发布或远程 PR 合并。
