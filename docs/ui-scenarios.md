# 日常 UI 行为场景与覆盖

[English](ui-scenarios.en.md) | 简体中文

本清单以使用意图和可观察结果为单位，共 142 项日常场景。不同历史长度、布局或输入样例是同一场景的变体，不能代替新的行为覆盖。

浏览器状态：`B` 表示至少一个代表行为已注册到 `pnpm test:ui-stability`；`G` 表示仍需补充浏览器行为验证。`B` 不代表该项所有分支及环境均已覆盖。命令也运行 `scripts/ui-behavior-suites.mjs` 中明确选定的功能行为测试，包括滚动行为回归。每节列出的组件测试是已有基础，不代表该节全部分支已通过整页验证。`DSH_UI_GROUP=daily` 仅运行完整 App 浏览器用例，`DSH_UI_SCENARIO` 仅运行指定浏览器用例；这两种筛选运行不包含功能测试组。实际命令结果以生成的 JSON 记录为准。原生文件、窗口、拖放、凭据、真实 DSH 和辅助技术还需要独立验收；不得由受控浏览器结果替代。

本轮验收范围：常用输入、发送、停止、队列编辑与入列、会话草稿与导航、附件、模型选择、审批提问、设置与导出弹窗及窄窗口操作。其余条目保留为后续清单，不作为本轮常见场景验收的完成条件。当前没有提供会话置顶和永久删除操作，已从清单排除。每项同时检查适用的成功、拒绝、取消、失败重试和迟到结果。

交叉条件：经典/聚焦布局；英文/中文；侧栏/编辑器及窄矮窗口；浅色/深色/高对比度；键盘/鼠标/输入法；动态效果开启/关闭与运行中切换；短/长会话；正常/延迟/断开传输。仅在条件会改变行为时组合，不机械做全笛卡尔积。
