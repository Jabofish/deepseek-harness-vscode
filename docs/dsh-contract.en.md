# DSH upstream contract and compatibility

[English](dsh-contract.en.md) | [简体中文](dsh-contract.md)

This document and its Chinese counterpart own exact DSH identities, wire differences and installation defaults. Implementation facts come from `SUPPORTED_DSH_VERSIONS`, versioned Adapters, `LATEST_PUBLISHED_DSH_VERSION` and sanitised contract fixtures. Similar version numbers do not establish compatibility. See the [capability matrix](capability-matrix.en.md) for implementation status and the [testing guide](quality.md) for validation and release checks.

## Reading the contract

Find the exact runtime in the table, then check its Adapter, pinned source and wire notes. Use the [architecture specification](architecture.en.md) for layer boundaries and [isolated validation](quality.md#isolated-native-dsh) for native tests. Keep field names, version identities and source hashes exact.

Check the interfaces consumed by the change and retain adjacent-version rejection and historical regressions. Version tables and installation defaults follow the code constants below; capability status follows the matrix.

## Upstream sources and installation defaults

The latest published package recorded by this repository is `@deepseek-ai/dsh@0.2.1-rc.3`; guided installation defaults to `@deepseek-ai/dsh@0.2.1-rc.2`. Sources are pinned in the version table; isolated validation is in the [testing guide](quality.md). This is the repository's adaptation snapshot; query remote npm `latest` / `next` separately. `LATEST_PUBLISHED_DSH_VERSION` and `DEFAULT_INSTALL_DSH_VERSION` own these values. Adding an Adapter does not change the default. Installation and updates use verified exact versions rather than floating dist-tags. Timed questions and other incomplete acceptance remain recorded in the matrix.

The historical Host API baseline is commit [`47f943859bef60e4160492346772ded9b24f765a`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859bef60e4160492346772ded9b24f765a): [RPC map](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859bef60e4160492346772ded9b24f765a/packages/host/apiproxy/src/api/rpc-map.ts), [events](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859bef60e4160492346772ded9b24f765a/packages/host/apiproxy/src/api/events.ts) and [tool catalogue](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859bef60e4160492346772ded9b24f765a/packages/core/tools). It applies to that Host API family. Check newer Connection/Gateway, typed Remote and Session Controller interfaces against their own target tag/commit and existing source files. In particular, the old RPC files no longer exist in `0.1.5-rc.2` / `0.1.5-rc.3`. Those two versions share the consumed Session Controller, typed Remote, Connection/Gateway and tool-runtime source, while retaining separate exact identities.
