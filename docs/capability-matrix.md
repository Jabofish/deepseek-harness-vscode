# 能力矩阵

本表只列出具体能力、当前可用范围、限制和完成状态。高级能力以所连接 DSH 的能力声明为准。

| 状态      | 含义                                         |
| --------- | -------------------------------------------- |
| `DONE`    | 能力完整可用，所需使用场景均已确认。         |
| `PARTIAL` | 已有可用功能，仍有范围限制或使用场景待确认。 |
| `TODO`    | 尚未提供可用功能。                           |

## 产品边界

- 文件编辑、资源管理器、终端和分栏使用 VS Code 原生能力；不另建 DSH Web 的 Dock、文件树、PTY 终端、浏览器或 Office 预览。
- 远程工作区使用工作区侧的 DSH 和文件系统；连接外部 DSH 不会自动映射服务器文件系统。
- 模型、提供方、预设、命令、工具、Skill、插件及可选服务来自上游结构化目录；上游没有提供的目录搜索不由扩展补造。
- 审批、问题、目标、后台任务、工作流和工具状态只取自结构化接口与事件。

版本与接口差异见[上游契约](dsh-contract.md)，分层与安全边界见[架构](architecture.md)，验证和发布要求见[质量流程](quality.md)。
