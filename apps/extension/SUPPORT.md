# Support · 支持

遇到问题时，请先确认：

- 使用 VS Code `1.125+`。
- 已安装 DeepSeek Harness `0.1.0-rc.6`，或按扩展内的引导完成安装。
- DSH 与 VS Code Extension Host 在同一台本机上运行。

如果问题仍然存在，请在 [GitHub Issues](https://github.com/Jabofish/deepseek-harness-vscode/issues) 提交：

1. 操作系统、VS Code 版本和 DSH 版本。
2. 可复现步骤和预期/实际结果。
3. 扩展中的脱敏诊断信息。

请勿提交 API key、密码、访问令牌、完整提示词或其他私密内容。

For support, please verify that you are using VS Code `1.125+`, DeepSeek Harness `0.1.0-rc.6`, and a local Extension Host. If the issue persists, open a [GitHub Issue](https://github.com/Jabofish/deepseek-harness-vscode/issues) with your OS, VS Code/DSH versions, reproducible steps, expected versus actual behavior, and redacted diagnostics.

Never include API keys, passwords, access tokens, full prompts, or other private data.
